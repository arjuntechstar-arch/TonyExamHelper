# Angular Specification

Shared:
Login, navigation, role guards, notifications, loading/error states.

Faculty:
Dashboard, subjects/courses, syllabus editor, material upload, processing status, exam-pattern configuration, generation, candidate review, validation results, question bank, model paper generation.

Student:
Dashboard, subject/unit/topic selection, practice configuration, practice player, result, analytics, weak-topic practice.

Admin:
Users/roles, templates, AI provider settings, audit.

Requirements:
Responsive UI, visible validation state, source metadata for faculty, draft/approved/rejected states, safe destructive actions, no accidental duplicate submissions.
