# Source Traceability

This coding pack is derived from the existing project specification
`AI_Question_Generation_End_to_End_Process.md`.

The source specification covers the problem, objectives, roles, syllabus/material processing, RAG, templates, difficulty/Bloom control, generation, validation, similarity, ranking, human approval, question bank, student practice, analytics, faculty workflow, APIs, database entities, technology stack, security, evaluation, implementation phases, research questions, MVP and future competitive-exam architecture.

This pack converts those requirements into implementation-oriented instructions. Exact LLM/vector DB choices, similarity thresholds and ranking weights remain configurable and should be experimentally selected.
