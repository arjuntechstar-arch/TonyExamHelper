# Implementation Plan

Phase 1: repository, Angular/FastAPI shells, config, health, logging, tests.
Phase 2: SQL Server, migrations, models and repositories.
Phase 3: authentication, password hashing, JWT/session mechanism and RBAC.
Phase 4: subject/course/syllabus CRUD.
Phase 5: PDF/DOCX/PPTX/TXT upload, extraction, cleaning, chunking and metadata.
Phase 6: embeddings, vector store adapter, indexing and retrieval.
Phase 7: template CRUD and selection.
Phase 8: LLM adapter, structured generation and retries.
Phase 9: validation, similarity and ranking.
Phase 10: faculty review, approval, question bank and model papers.
Phase 11: student practice, mock tests, scoring and explanations.
Phase 12: analytics and weak-topic identification.
Phase 13: repeatable research evaluation.
Phase 14: security, integration, E2E and performance tests.
Phase 15: README, API docs and deployment.

After each phase: build → test → fix → document.
