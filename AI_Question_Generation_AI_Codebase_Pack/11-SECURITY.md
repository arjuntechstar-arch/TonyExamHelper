# Security

- Authentication and RBAC.
- Secure document upload and MIME/type/size validation.
- Protect student performance data.
- Restrict question-bank access.
- Audit approvals/edits.
- Never log passwords/tokens/secrets.
- Rate-limit generation endpoints.
- Treat uploaded documents as untrusted prompt content.
- Validate approved knowledge sources.
- Enforce ownership boundaries for future multi-institution support.
