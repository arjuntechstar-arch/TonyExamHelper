# Requirements

## Roles
Student: choose subject/unit/topic, configure practice, answer questions, see explanations and performance, receive targeted practice.

Faculty: manage syllabus/materials/patterns, generate questions, review/edit/approve/reject, create question banks and model papers.

Admin: manage users, roles, templates, AI configuration and audit information.

## Question types
MCQ, Short Answer, Long Answer, Case Based, Mixed.

## Patterns
MCQ: Direct Concept, Scenario Based, Statement Based, Assertion and Reason, Case Based, Application Based.
Short: Define, Explain, Compare, Differentiate, Apply.
Long: Explain, Analyze, Compare, Case Study, Design, Problem Solving.

## Difficulty
Easy, Medium, Hard.

## Bloom
Remember, Understand, Apply, Analyze, Evaluate, Create.

## Syllabus
Subject → Course → Unit → Topic → Subtopic → Learning Objective.

## Quality checks
Correctness, relevance, syllabus compliance, pattern compliance, difficulty, Bloom level, completeness, MCQ distractor quality, semantic duplication.

## Human approval
AI Generation → Automated Validation → Teacher Review → Approve/Edit/Reject → Question Bank.

## MVP
PDF/DOCX upload → extraction → chunking → embeddings → vector search → RAG → LLM → MCQ/Short/Long → difficulty → basic validation → duplicate detection → question bank → mock test.
