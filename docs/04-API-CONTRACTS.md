# API Contracts

Base path: `/api`

Interactive schemas are generated by FastAPI at `/docs` (Swagger UI) and
`/redoc`. Unless noted otherwise, protected endpoints require
`Authorization: Bearer <access_token>`. Errors use the common
`error`, `message`, `request_id`, and optional `details` response shape.

All endpoints require request validation, RBAC where applicable, consistent
error responses and request/correlation IDs. Upload processing uses the
configured `MATERIAL_STORAGE_PATH`; generation defaults to the deterministic
provider unless `LLM_PROVIDER` is changed.
